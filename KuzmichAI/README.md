# Кузьмич: голосовой ассистент для Unitree G1

Копия исходного кода из золотого бэкапа `KuzmichAI_v2_EGOR_ZOLOTOY_20260910_123307.zip` от 10 сентября 2026 года. Подготовлена для размещения на GitHub 7 октября 2026 года.

Это сохранённая версия системы, а не снимок текущего состояния сервера. Поведение исходного кода при подготовке этой копии не изменялось. Ассистент и движения робота не запускались.

## Состав

- STT: GigaSTT; в коде также имеются другие варианты распознавания.
- LLM: локальная GGUF-модель Qwen; reasoning отключён настройками запуска.
- TTS: Silero `v5_5_ru`, мужской голос `aidar`.
- База знаний: `kb_dump.json`, `kb_index.faiss`, `kb_mapping.pkl`.
- Голосовой конвейер: `main.py`, `audio_io.py`, `stt_engine.py`, `llm_engine.py`, `tts_engine.py`.
- Работа с базой и кэшем: `semantic_cache.py`, `cache_manager.py` и скрипты сборки.
- Интеграция жестов и описания поз: `g1_greeting_gestures.py`, `g1_arm_preset_actions/`.
- Настройка и запуск: `setup.sh`, `start.sh`, `stop.sh`, `requirements.txt`.

В архив публикации не включены веса моделей, виртуальное окружение, аудиозаписи, логи, пользовательский кэш и сторонний бинарный комплект Piper. Файлы базы знаний сохранены. `.gitignore` предотвращает случайное добавление таких локальных файлов в Git.

## Подготовка к запуску

Проект предназначен для Linux. Веса моделей и Python-зависимости нужно установить отдельно; этот бэкап не является готовым окружением. `setup.sh` содержит прежнюю настройку окружения и CUDA: изучите его перед выполнением на другой машине.

В `start.sh` сохранены параметры исходного сервера. Перед запуском проверьте:

- `VOICE_ENGINE_LLM_MODEL`: в бэкапе указан старый абсолютный путь на сервере. Для модели внутри проекта замените его на `${PWD}/models/qwen3_5_4b/Qwen3.5-4B-Instruct-Q4_K_M.gguf`.
- `VOICE_ENGINE_GIGASTT_MODEL_DIR`: папка с установленной моделью GigaSTT.
- `VOICE_ENGINE_ROBOT_IP`, сетевой интерфейс и пути воспроизведения: параметры вашей машины и робота.
- `VOICE_ENGINE_ENABLE_GESTURES`: в исходной версии установлен `true`. Для проверки голоса без движений установите `false` перед запуском.
- `HF_HUB_OFFLINE` и другие offline-параметры: запуск рассчитывает на уже загруженные модели, включая модель эмбеддингов и VAD.
- Резервный Piper: в этой копии его бинарные файлы отсутствуют. Для этого backend потребуется отдельная установка.

После подготовки окружения и проверки настроек запуск выполняется вручную:

```bash
chmod +x start.sh stop.sh
./start.sh
```

`start.sh` включает автоматический перезапуск процесса. Остановка: `Ctrl+C` в терминале запуска.

Motion API работает отдельным процессом на роботе. В исходной рабочей схеме его адрес был `http://192.168.1.103:8091`. Проверка доступности без запуска движения:

```bash
curl --connect-timeout 3 http://192.168.1.103:8091/api/status
```

Движения запускаются только по явной команде оператора рядом с роботом.
